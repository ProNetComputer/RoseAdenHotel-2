⚙️ إعدادات الربط المباشر مع مستودع GitHub

💡 هذه اللوحة تتيح لك تعديل أسعار الغرف وبيانات الفندق مباشرة من المتصفح وحفظها في مستودع GitHub الخاص بك بنقرة واحدة دون الحاجة لأي سيرفر خارجي!
يمكنك إنشاء رمز برمجيات مجاني من إعدادات حسابك في GitHub: Settings → Developer Settings → Personal Access Tokens مع تفعيل صلاحية (repo).

🏨 البيانات العامة ومعلومات الاتصال

🛏️ إدارة الغرف والأسعار والمميزات

قم بتعديل أسعار الغرف أو مسمياتها وشاراتها الترويجية أدناه، ثم انتقل لتبويب النشر لحفظها مباشرة على GitHub.

🎓 قاعة التدريب والفعاليات

🚀 نشر التعديلات وتحديث موقع GitHub Pages

عند النقر على زر النشر، سيقوم النظام بعمل Commit تلقائي إلى ملفات data/*.json في مستودع GitHub الخاص بك. سيقوم GitHub Pages تلقائياً بإعادة بناء ونشر الموقع خلال 30 إلى 60 ثانية!
