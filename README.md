### 🌟 نظرة عامة على المشروع (Project Overview)
تمت إعادة بناء وتطوير موقع **فندق روز عدن 2 السياحي** ونقله من صفحة واحدة ضخمة غير منظمة (Monolithic Single-Page بحجم يتجاوز 3.15 ميجابايت بسبب دمج الصور والأكواد المضمنة Base64) إلى **مشروع ويب متكامل واحترافي متعدد الصفحات (Multi-Page Architecture)** بمعايير برمجية عالمية نظيفة وقابلة للتوسع والصيانة السهلة.

### 🚀 كيفية رفع المشروع وتشغيله على GitHub Pages

1. **إنشاء مستودع جديد على GitHub**:
   - توجه إلى [GitHub](https://github.com/) وقم بإنشاء مستودع جديد باسم `rose-aden-hotel`.
2. **رفع الملفات إلى المستودع**:
   - يمكنك رفع الملفات عبر أداة `Git CLI`:
     ```bash
     git init
     git add .
     git commit -m "Initial commit: Rose Aden 2 Hotel multi-page modular project"
     git branch -M main
     git remote add origin https://github.com/USERNAME/rose-aden-hotel.git
     git push -u origin main
     ```
   - أو سحب وإفلات الملفات مباشرة في واجهة موقع GitHub.
3. **تفعيل استضافة GitHub Pages**:
   - ادخل إلى إعدادات المستودع: **Settings** -> **Pages**.
   - تحت قسم **Build and deployment**:
     - اختر Source: **Deploy from a branch** (أو **GitHub Actions** إذا كنت تستخدم ملف `.github/workflows/deploy.yml`).
     - اختر Branch: `main` والمجلد `/ (root)`.
     - اضغط **Save**.
   - خلال ثوانٍ سيصبح موقعك متاحاً مجاناً برابط: `https://USERNAME.github.io/rose-aden-hotel/`.

### 🛠️ لوحة التحكم وإدارة التعديلات عبر GitHub (Control Panel)

تم تزويد المشروع بصفحة كنترول بنل متقدمة وخفيفة داخل مجلد `/admin/index.html`، مصممة خصيصاً للعمل بسلاسة مع GitHub:

#### 1. كيف تعمل اللوحة مع GitHub Pages بدون سيرفر؟
- اللوحة تعتمد على تقنية **Client-Side Git CMS** عبر واجهة برمجة تطبيقات **GitHub REST API**.
- يقوم المشرف بحفظ بيانات المستودع ورمز وصول شخصي (Personal Access Token - PAT) لمرة واحدة فقط في المتصفح.
- عند تعديل الأسعار أو الهواتف أو الغرف والنقر على **"حفظ ونشر التعديلات على GitHub"**:
  1. تقوم اللوحة بقراءة ملفات `data/*.json` المعدلة.
  2. تقوم بعمل تشفير Base64 للبيانات.
  3. تتصل بـ GitHub API وتقوم بعمل `Commit` مباشر إلى المستودع.
  4. فور اكتمال الـ Commit، يقوم GitHub Pages تلقائياً بإعادة نشر وتحديث الموقع الحي خلال 30 إلى 60 ثانية!

#### 2. كيفية استخراج رمز GitHub Personal Access Token (PAT):
1. في حسابك على GitHub، اضغط على صورتك الشخصية &rarr; **Settings**.
2. انزل إلى أسفل القائمة الجانبية واضغط على **Developer Settings**.
3. اختر **Personal access tokens** &rarr; **Tokens (classic)**.
4. اضغط على **Generate new token (classic)**.
5. حدد صلاحية: `repo` (Full control of private repositories).
6. انسخ الرمز والصقه في تبويب "إعدادات مستودع GitHub" داخل لوحة التحكم.

#### 3. خيار التعديل اليدوي / الاحتياطي:
- وفرنا أيضاً زراً لتحميل ملفات JSON المعدلة يدوياً (Download JSON Package) في حال رغب المشرف بإجراء التعديلات محلياً ورفعها عبر GitHub Desktop أو Git CLI.

### 💡 اقتراحات بديلة للوحات التحكم (Alternative CMS Recommendations)

إذا أردت خيارات إضافية لإدارة المحتوى تناسب الفرق غير التقنية، نقترح الحلول التالية:

1. **Decap CMS (Netlify CMS سابقاً)**:
   - نظام CMS مفتوح المصدر ومبني لـ Git بنسبة 100%.
   - يوضع ملفان فقط: `admin/index.html` و `admin/config.yml`.
   - يوفر واجهة بصرية لرفع الصور وتعديل الغرف مع دعم التدوينات والصفحات.
2. **ربط الموقع بـ Google Sheets API**:
   - يمكن جعل الموقع يقرأ أسعار الغرف وأرقام الهواتف مباشرة من جدول Google Sheet مجاني.
   - الميزة: سهولة بالغة لموظفي الاستقبال لتغيير الأسعار في جدول إكسل فيتحدث الموقع فوراً دون انتظار إعادة بناء GitHub.
3. **Headless CMS مثل Supabase أو Firebase**:
   - مناسب إذا أردت مستقبلاً نظام حجز ودفع إلكتروني متكامل وقاعدة بيانات للنزلاء.
